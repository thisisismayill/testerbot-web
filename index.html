Saytın haqqında bilmək istədiyin hər şey

Bir crawl — həm sınaq, həm kəşfiyyat, həm də rəqib analizi.

Xətaları tapır

Bot saytı insan kimi gəzir — klikləyir, formaları doldurur, hər şeyi sınayır.

  • JavaScript xətaları, konsol səhvləri
  • Sınıq linklər, 404/500, yüklənməyən şəkillər
  • Ölü düymələr, işləməyən formalar
  • Mobil daşma, əlçatanlıq (axe-core)

Saytı tanıyır

Sayt nə ilə qurulub, nə qədər güclü və sürətlidir — hamısı bir baxışda.

  • Domen avtoritetliyi (0–10)
  • Real performans — LCP, INP, CLS
  • Texnologiya stəki (WordPress, React…)
  • Hosting, CDN, server

Rəqibləri göstərir

Öz backlink indeksin və Domain Authority metrikin — açarsız, öz datandan.

  • Domain Authority reytinqi (1–100)
  • Kim kimə link verir (backlinklər)
  • Link Intersect — backlink fürsətləri
  • Böyüyən indeks (SQLite)
Sayt kəşfiyyatı

Hər hesabatın yuxarısında tam mənzərə

Bir sayt gəzəndə bot sənə yalnız xətaları yox, saytın kim olduğunu da deyir — avtoritet, performans, texnologiya və hosting, hamısı bir yerdə.

  • Google-un öz performans datası (CrUX)
  • Link qrafı + saytın ən güclü səhifələri
  • İngiliscə HTML hesabat + skrinşotlar

Link Intersect

Rəqiblərinə link verən, sənə verməyən domenlər

İndeksə bir neçə rəqib sayt ver — bot sənə deyil, onlara link verən domenləri tapır. Bunlar sənin əldə edə biləcəyin ən dəyərli backlinklərdir. Ahrefs-in flaqman funksiyası, öz datandan.

  • Neçə rəqibə link verdiyinə görə sıralanır
  • Hər domenin öz avtoritet skoru
  • Follow / nofollow ayrımı
